# 🧠 Radxa Cubie A7Z - ExecuTorch Deployment Guide

This guide provides the exact commands to set up and run the YOLOv26 ExecuTorch models on your Radxa Cubie A7Z board.

## 🛠️ 1. Environment Setup (On the Board)

Run these commands in your terminal on the Radxa board:

```bash
# Update and install system dependencies
sudo apt-get update
sudo apt-get install -y python3-pip python3-venv libopencv-dev

# Create a virtual environment
python3 -m venv executorch-env
source executorch-env/bin/activate

# Install ExecuTorch and requirements
# Note: In 2026, standard pip install works for ARM64
pip install executorch opencv-python pyyaml numpy
```

## 📂 2. Model Retrieval

Once you have pushed the files to GitHub, clone them on the board:

```bash
git clone <your-repo-url>
cd <repo-folder>
```

Ensure you have these files:
- `models/yolo26s_executorch_model/yolo26s.pte`
- `models/yolo26_seg_executorch_model/yolo26_seg.pte`
- `tools/video_inference_executorch.py`

## 🚀 3. Running Inference (Optimized)

The Radxa Cubie A7Z has a hybrid architecture (2x A76 "Big" cores + 6x A55 "Little" cores). To get the best FPS, you should force the process to run on the **Big cores (CPUs 0-1)**.

### Detection Test (Car Video)
```bash
taskset -c 0,1 python tools/video_inference_executorch.py \
  models/yolo26s_executorch_model/yolo26s.pte \
  car_video.mp4
```

### Segmentation Test (Currency Video)
```bash
taskset -c 0,1 python tools/video_inference_executorch.py \
  models/yolo26_seg_executorch_model/yolo26_seg.pte \
  currency_video.mp4
```

## 📈 Performance Tips for A733
*   **Thermal Throttling**: The A733 can get hot during continuous inference. Ensure you have a heatsink or fan on the Radxa Cubie A7Z.
*   **Batching**: Stay with `batch=1` for real-time video processing to keep latency low.
*   **XNNPACK**: ExecuTorch automatically uses XNNPACK on ARM64, which is why we get such good performance on the A76 cores.
